Generalized Agent Iteration Unifies Policy Improvement and Recursive Self-Improvement

rss ArXiv cs.AI · 2026-09-16 · ⌛ 4 min read
Reason：The paper proposes a novel formal framework unifying iterative policy improvement and recursive self-improvement, offering theoretical clarity for AI researchers and alignment discussions. No comments were provided to assess discussion quality.
📰 What's New
arXiv:2609.13406 introduces Generalized Agent Iteration (GAI), a formal framework that models iterative policy improvement and recursive self-improvement (RSI) as a single learning paradigm. GAI defines an agent as a configuration of modifiable components within a system, and describes learning as a cycle of agent evaluation and agent improvement. Two pivotal dials distinguish instances: whether the improving mechanism is part of the agent, and whether the evaluation standard is grounded outside it. The first dial separates generalized policy iteration (GPI) from RSI; the second determines whether a system is anchored, drifting in goals, or fully self-referential.
💡 Why It Matters： For AI researchers and alignment work, GAI provides a coordinate system to place existing systems on the same two axes and to state defects of recursive self-improvement one condition at a time. It converts RSI from a loose prospect into a formally analyzable object, offering a principled basis for comparing and designing new self-improving systems. This could influence reinforcement learning, AI safety, and the evaluation of autonomous agents.
Background
Generalized policy iteration (GPI) is a classical reinforcement learning framework that alternates policy evaluation and policy improvement, with the update rule and evaluation base typically outside the agent. Recursive self-improvement (RSI) refers to agents modifying their own code or learning mechanisms, long discussed but lacking a unified formal description. GAI brings both under one cycle and uses two dimensions to characterize their differences.
Key Details
The agent is represented as a configuration of modifiable components rather than a single policy. The core cycle has two phases: agent evaluation and agent improvement. The two dials are whether the improving mechanism is inside the agent and whether the standard is grounded outside, yielding three polarities: anchored, goal drift, and fully self-referential.

Asclepius Adaptive Harness Improves Clinical Agent Critical Actions by 22%

rss ArXiv cs.AI · 2026-09-16 · ⌛ 5 min read
Reason：Presents a novel adaptive scaffolding (Asclepius) and identifies concrete long-horizon failure modes for clinical LLM agents, providing useful directions for practitioners; no community comments available to assess discussion quality.
📰 What's New
Researchers introduced Asclepius, an adaptive agent scaffolding for long-horizon clinical tasks, and evaluated it on the Clinical Environment Simulator (CES), where an agent manages an entire emergency-department shift under continuous time and resource pressure. On CES, current agents reach the correct diagnosis in most cases but fail to deliver complete and timely critical actions. Asclepius improves critical-action correctness by 22% (p=0.024) on held-out batches never observed during harness evolution while preserving diagnostic accuracy, and on the full ten-batch set improves critical actions by 25% and timeliness by 13%.
💡 Why It Matters： This shows the main bottleneck for clinical LLM agents is not diagnostic reasoning but long-horizon execution reliability; emergency departments require agents that can sustain performance over hours under resource contention. The finding that three failure modes form a coupled bottleneck means deployments must address instruction-adherence drift, treatment incompleteness, and severity-equity gaps together to close the execution gap, providing a concrete direction for healthcare AI practitioners.
📊 Key Facts: 22% 25% 13%
Background
The Clinical Environment Simulator (CES) emulates an emergency-department shift, requiring an agent to manage multiple patients under continuous time and resource pressure. Most LLM agent benchmarks evaluate only short, single-task trajectories, while real deployments can run for hours and surface a different class of failures. The execution gap refers to agents reaching the correct diagnosis but failing to complete all necessary critical actions on time.
Key Details
Asclepius has three components: a self-evolving harness that rewrites the operating manual between shifts from trace-level feedback, an externalized clinical skills library for high-stakes regimen knowledge, and three isolated subagents that partition per-turn decisions across the patient queue. The three long-horizon failure modes are operationalized as per-trace counters: instruction-adherence drift, treatment incompleteness, and a severity-equity gap in timeliness. Evaluation on held-out batches used five LLM judges from three model families.
