📰 What's New
Researchers introduced TEX, a collaborative test-time scaling framework that parallelizes agents to generate tests and patches and cross-executes each test against every patch to form a K×K feedback matrix. On SWT-Bench Verified, TEX achieves 86.4%, a new state-of-the-art and a +9.0% improvement over single-agent baselines. Random selection from TEX outputs reaches 84.4%, surpassing the previous SOTA of 84.0%. This indicates execution-grounded cross-validation improves solution quality, not just best-case samples.
💡 Why It Matters： By replacing verbose trace sharing with objective execution feedback, TEX provides a scalable mechanism for long-horizon agentic tasks such as test-case generation and software engineering. The +9.0% SOTA gain on SWT-Bench Verified directly affects teams building LLM coding agents, showing that cross-candidate execution validation can outperform isolated or trace-aggregated test-time scaling methods.
📊 Key Facts: 86.4% +9.0% 84.4%
Background
SWT-Bench Verified is a benchmark for evaluating software engineering agents on real-world tasks; previous state-of-the-art performance was 84.0%. Test-time scaling refers to techniques that increase computation at inference to improve model outputs, often by sampling multiple candidates. Existing methods either isolate individual candidates or aggregate their traces, which may not scale to long-horizon tasks requiring test generation and code repair. TEX's execution-based cross-validation uses actual code execution results as feedback rather than relying on shared reasoning traces.
Key Details

The approach avoids verbose trace sharing while enabling objective validation; random selection from TEX outputs (84.4%) also exceeds the previous single-agent SOTA (84.0%).

More Memory, Worse Agents: Error Reproduction and Anti-Persistence in LLM Agents

rss ArXiv cs.AI · 2026-10-21 · ⌛ 5 min read
Reason：The paper introduces a novel failure mode (error reproduction) in LLM agents with memory abstractions and proposes a specific solution (Anti-Persistence). This is technically deep and directly relevant to AI practitioners designing agent architectures, with potential to influence how memory is managed in production systems. No comments provided, so discussion quality cannot be assessed.
📰 What's New
An arXiv preprint (2610.27406) identifies a failure mode called error reproduction: when LLM agents store inferred rules, summaries, and skills, errors in those abstractions are retrieved and reused, then shape execution trajectories that become the basis for new abstractions. The authors propose Anti-Persistence, a memory design that accumulates trajectories and outcomes but reconstructs task-specific guidance on demand. An adaptive selector uses prior outcomes to decide whether and how to synthesize guidance, which is discarded after execution. Across different benchmarks and backbones, Anti-Persistence achieves higher overall held-out success and the lowest average LLM-call cost among evaluated memory designs.
💡 Why It Matters： For AI practitioners building agent architectures, this identifies a concrete reason why more memory can degrade performance and suggests separating experience accumulation from abstraction persistence. It may influence how production systems manage memory for self-improving agents, potentially reducing erroneous reuse and LLM call costs. The design could shift best practices away from persistent skill pools toward ephemeral synthesized guidance.
Background
LLM agents can improve without parameter updates by storing past execution experience in external memory. A design choice is whether to store only raw trajectories and outcomes, or also derived abstractions such as rules, summaries, and skills. Abstractions are more reusable but can embed errors that later get retrieved and reused. Persistent memory across sessions increases the chance that faulty abstractions influence future behavior.
Key Details
The persistent abstraction memory stores rules, summaries, and skills inferred from execution trajectories. Anti-Persistence keeps raw trajectories and outcomes but does not persist synthesized guidance; an adaptive selector decides at query time whether to reconstruct guidance and then discards it after the execution step. The method is evaluated across multiple benchmarks and backbone models using held-out success and average LLM-call cost as metrics.

Pareto-Optimal RTL Code Generation via Multi-Objective Reinforcement Learning with LLMs

rss ArXiv cs.AI · 2026-10-21 · ⌛ 5 min read
Reason：Novel research on multi-objective reinforcement learning for LLM-based RTL generation, addressing diversity of Pareto-optimal solutions with high technical depth; no community discussion available.
📰 What's New
Researchers propose the first method for LLM-based RTL circuit generation that optimizes the quality and diversity of the entire generated circuit set in power, performance, and area (PPA) space. The approach reformulates coverage improvement of the Pareto solution set into a sequential circuit generation problem and uses a Hypervolume Contribution (HVC) reward to measure each circuit's contribution to the Pareto front. On the RTLLM v2 benchmark, the method achieves +13.3 percentage points relative Hypervolume compared to a baseline without PPA optimization and +14.4 percentage points over a single-objective reinforcement learning method. It also demonstrates superior circuit diversity.
💡 Why It Matters： This enables chip designers to obtain multiple Pareto-optimal RTL implementations after a single training run and select the preferred power-performance-area trade-off for a given product. The shift from scalar reward aggregation to multi-objective coverage addresses practical design requirements where objective weights vary by product constraints. It could reduce iteration cycles in RTL design by automating generation of diverse high-quality hardware implementations.
📊 Key Facts: 13.3 14.4
Background
RTL (register-transfer level) is a hardware description abstraction used to design digital circuits, typically in Verilog or VHDL. PPA stands for power, performance, and area—three competing objectives in chip design. Pareto-optimal solutions are those where no objective can be improved without worsening another. Reinforcement learning with verifiable rewards (RLVR) uses automatically checkable objectives to train LLMs, but prior work combined multiple PPA goals into a single scalar reward.
Key Details
The training pipeline is generation-based: it formulates coverage improvement of the entire Pareto solution set as a sequential circuit generation problem. The reward function uses Hypervolume Contribution (HVC), which quantifies how much a newly generated circuit expands the Pareto front in PPA objective space. Evaluation was performed on the RTLLM v2 benchmark.

LLM planning difficulty depends on structural complexity and predicate semantics

rss ArXiv cs.AI · 2026-10-21 · ⌛ 5 min read
Reason：This arXiv paper provides a systematic empirical analysis separating structural complexity from semantic interpretability in LLM planning, revealing a notable drop in success under predicate renaming; it offers valuable insights for AI researchers and practitioners. No community discussion or engagement signals are provided.
📰 What's New
Researchers evaluated seven STRIPS domains with BFS-optimal plan lengths and found that the zero-training delete-relaxation heuristic h_add achieved a mean Spearman |ρ| of 0.931 for structural difficulty prediction, outperforming ridge regression (0.707), object count (0.657), and the episodic retrieval architecture ARC (0.400). Progressive renaming of predicates while preserving states, transitions, and optimal plans caused valid LLM planning success to drop from 67.5% to 40.0% between 0% and 100% renaming, with refusals remaining at 0%. An LLM given ARC's conditioning information predicted difficulty in context at a mean |ρ| of 0.826, exceeding the trained ARC model. Hybrid routing between an LLM and a symbolic planner depended more on calibration to the target LLM's outcomes than on the chosen structural score.
💡 Why It Matters： These findings suggest that symbolic heuristics such as h_add already estimate structural planning difficulty well, so AI researchers should shift effort toward modeling how predicate semantics influence LLM behavior. Practitioners building hybrid neurosymbolic planners can achieve better routing by calibrating to the specific LLM's success and refusal patterns rather than engineering new structural predictors. This could focus resources on semantic robustness and reduce failures in real-world LLM planning systems.
📊 Key Facts: 67.5% 40.0% 0%
Background
STRIPS is a classical planning representation in which states are sets of propositions, and actions have preconditions and effects. h_add is a common domain-independent heuristic that solves a relaxed version of the planning task by summing estimated costs, often used to guide search. Predicate names in planning benchmarks may carry semantic meaning that LLMs use, beyond the formal structure. Renaming predicates while preserving the transition system tests how much performance depends on semantic recognition versus pure combinatorial difficulty.
Key Details
The h_add heuristic is a delete-relaxation method that estimates goal distance by ignoring action deletes, and it required no training to achieve the 0.931 correlation. The ARC episodic retrieval architecture did not outperform a linear model using the same features, suggesting its retrieval mechanism added little for structural prediction. Predicate renaming isolated semantic interpretability by preserving the underlying state graph and optimal plan lengths, while an LLM using ARC's conditioning information achieved 0.826 mean correlation compared to trained ARC's 0.400.

📰 What's New
Researchers evaluated a single-LLM baseline and three multi-agent topologies across four LLMs on three clinical tasks. Of 36 model-system-task comparisons, 12 differences were large enough to resolve; hallucination decreased in 4 and increased in 8. No topology was reliably better than another, and the deciding factor was the model rather than topology or agent count. In a self-correction test, every model except Llama-3.2-3B-Instruct reduced hallucination after seeing its own flagged errors.
💡 Why It Matters： Clinical AI systems are often assumed more trustworthy when they improve task scores, but this work separates final-answer accuracy from reasoning reliability. Clinicians rely on stated rationales, so hallucination in reasoning can lead to unsafe decisions even when conclusions are correct. The finding that collaboration does not inherently reduce hallucination means developers cannot treat multi-agent architectures as a trustworthiness fix and must evaluate rationale-level hallucination directly.
📊 Key Facts: 3.2
Background
Multi-agent LLM systems use several language models that interact, debate, or review each other's outputs. Hallucination in LLMs refers to generated text that is not grounded in input facts (factuality) or not faithful to the model's own reasoning (faithfulness). Clinical tasks often require not just a correct answer but a reliable rationale for clinician trust. This preprint (arXiv:2610.27027) evaluates whether collaboration reduces hallucination in reasoning, not just final answers.
Key Details
The study scored hallucination using a factuality and faithfulness taxonomy inside the rationale each system generates, reporting it alongside the task metric. It tested four LLMs (including Llama-3.2-3B-Instruct) and three multi-agent topologies, plus a single-LLM baseline. The self-correction experiment showed the collaboration-lowered-hallucination model gained the most, while Llama-3.2-3B-Instruct—whose hallucination collaboration amplified most—did not reduce hallucination at all.
