Study: 14 LLM Agents Overtrust Unreliable Tools; Web Search Adoption Reaches 68%

rss ArXiv cs.AI · 2026-09-09 · ⌛ 5 min read
Reason：Important empirical study revealing high overtrust in unreliable tool outputs across 14 LLMs, with a specific failure mode where agents internally correct errors but output corrupted answers; highly relevant to AI agent reliability and safety, though not a new architecture or paradigm shift.
📰 What's New
Researchers evaluated fourteen LLMs across three tools—web search, LLM sub-agent delegation, and code execution—by corrupting tool returns and measuring adoption in final answers. The mean adoption rate exceeded one third for every tool and reached 68.0% for web search. Reasoning trace analysis found that agents often recognized conflicts, recovered the correct answer internally, but presented only the corrupted answer without warning the user.
💡 Why It Matters： This overtrust failure mode directly affects AI agent reliability in production systems where tool outputs can be plausible but incorrect. If agents silently adopt corrupted web search or code execution results, downstream decisions in finance, healthcare, or software engineering could propagate errors without detection. The lack of a consistent mitigation across prompting, metadata, and post-training means current agents remain vulnerable; designers must build output validation and conflict communication mechanisms.
📊 Key Facts: 68.0%
Background
Tool-using LLM agents call external tools such as search engines, code interpreters, or other models to complete tasks. Existing evaluations typically assume tool returns are reliable, but real-world tools can return plausible yet incorrect information due to stale data, parsing errors, or model hallucination. Overtrust occurs when an agent adopts these outputs without verification, enabling error propagation. Analyzing reasoning traces—the intermediate steps a model takes before producing a final answer—helps identify where the agent fails to validate or communicate conflicting information.
Key Details
The study corrupted tool returns for three modes and measured adoption in final answers across fourteen LLMs. Reasoning traces revealed a specific failure: agents internally recovered correct answers in some cases but still emitted only corrupted content without user warnings. Interventions included user prompting, tool provider metadata, and agent builder post-training; some helped specific model-tool pairs but none consistently reduced overtrust across all tools.

Six-Month Study: Operating Layer Not Strategy Text Drives LLM Trading Agents

rss ArXiv cs.AI · 2026-09-09 · ⌛ 6 min read
Reason：Novel population-scale empirical study of production LLM trading agents with large dataset and causal findings, highly relevant for AI practitioners and investors in trading/fintech; no comments provided to assess discussion quality.
📰 What's New
A six-month population-scale study recorded 7.5 million single-model invocations, about 300,000 onchain actions, and 14,596 fills across two production LLM trading agent fleets: DX Terminal Pro (3,505 user-funded vaults trading ETH on Base for 21 days from February to March 2026) and the DXAP live alpha fleet (500 to 599 user-created agents trading Hyperliquid perpetuals from June to August 2026). The operating layer determined behavior more than strategy text: a risk slider explained leverage of +0.425 per level, agent fixed effects absorbed 60% of variance, and a leaderboard render boundary causally routed selection with a regression discontinuity of 1.75x at the top-3 cut. Sizing was volatility-blind, with median leverage 5.0x in every volatility sextile, and one posture-slider cell holding 11% of the book accounted for 62% of liquidations. The DXAP fleet was not profitable and trailed a matched Hyperliquid retail benchmark with a 41% versus 50% roundtrip win rate.
💡 Why It Matters： For anyone deploying or funding LLM trading agents, the results imply that tuning strategy prompts is less important than setting risk sliders, leaderboard cutoffs, and posture presets; these operating-layer controls directly shift leverage, liquidation concentration, and agent selection. The absence of directional edge in both fleets and the 41% versus 50% win rate against a retail benchmark suggest that production LLM traders currently fail to outperform simple retail baselines, with implications for capital allocation in crypto and fintech.
📊 Key Facts: 60% 11% 62%
Background
Autonomous language-model trading agents use LLMs to parse market data and submit trades through exchange APIs. Hyperliquid perpetuals are leveraged derivatives that track crypto prices without expiry; liquidation occurs when losses exceed margin. Regression discontinuity exploits a sharp cutoff—here the top-3 leaderboard boundary—to estimate causal effects. Agent fixed effects isolate persistent differences among individual agents, and a bracket order is a mechanical stop/take-profit rule.
Key Details
The paper uses regression discontinuity at the top-3 leaderboard cut (1.75x selection effect), agent fixed effects absorbing 60% of behavior variance, and a risk slider coefficient of +0.425 leverage per level. A mechanical bracket recovers +39.0 bps per position, whereas 49.3% of positions that reached +300 bps favorable excursion within 24h still closed negative. A paired-replay league of frontier models on 416 captured production scenarios found decision quality statistically indistinguishable at this horizon.

AutoFyn: Non-Parametric Expert Iteration for Long-Horizon Agents

rss ArXiv cs.AI · 2026-09-09 · ⌛ 4 min read
Reason：Novel agent architecture using persistent state instead of weight updates, with demonstrated application across olympiad math, data science, and cybersecurity—high technical value for AI practitioners, though no community discussion or market signal provided.
📰 What's New
AutoFyn is an agent harness based on Expert Iteration that updates persistent state from verified rewards across rounds instead of updating model weights. On the six fresh problems of the 2026 International Mathematical Olympiad, every model with room to improve scored higher under AutoFyn than in its provider's own coding agent. AutoFyn also built the top-ranked agent on the Spider 2.0 dbt benchmark, and produced 16 maintainer-confirmed vulnerability advisories in Next.js, MetaMask, pnpm, Warp, LiteLLM, Langflow, and Open WebUI.
💡 Why It Matters： By replacing weight updates with persistent state, AutoFyn enables frozen models to improve on long-horizon tasks without expensive fine-tuning, using only explicit memory files, reports, and repository state. Its results across olympiad math, data science, and cybersecurity suggest that external state and verification loops can push general-purpose models to leading performance on specialized benchmarks, with direct implications for autonomous vulnerability discovery and AI agent engineering.
📊 Key Facts: 2.0
Background
Expert Iteration is a reinforcement learning paradigm that typically distills expert behavior into network weights; AutoFyn instead treats the model as frozen and accumulates expertise in persistent state that can be explicitly loaded across sessions. This state includes memory files, reports, and code repository content, and it changes only through verified reward signals. The approach is non-parametric because no gradient updates are applied to the underlying model.
Key Details
Each round starts from a fresh model session, and durable information is reintroduced only through explicit interfaces such as persistent memory files, reports, and repository state. Within a round, an orchestrator explores, plans, and builds multiple alternative approaches with specialized agents, while a task-grounded verifier supplies an objective reward that is distilled back into the persistent state to update the next round's effective policy.

ARC-Bench Shows Frozen JEPA World Models Misrank Actions

rss ArXiv cs.AI · 2026-09-09 · ⌛ 4 min read
Reason：Important technical audit of frozen JEPA world models, introducing a benchmark that reveals structural failure in action ranking; relevant to AI researchers and could influence model selection, but limited to a specific technical issue without broader market or economic impact. No discussion comments provided.
📰 What's New
ARC-Bench, a no-leak fixed-candidate protocol, measures whether frozen JEPA-style objectives rank candidate actions correctly, and it was applied to official released JEPA-WM checkpoints across navigation and manipulation-style control. On official manipulation audits the top-scored candidate is almost always suboptimal, and the same inversion appears in maze domains. Replacing DINOv2 with video-pretrained V-JEPA 1 and V-JEPA 2 encoders at ViT-L/ViT-G scale did not remove the defect. Provenance, undertraining, matched-budget backbone controls, and metric-circularity controls rule out trivial explanations.
💡 Why It Matters： This defect matters for AI researchers and engineers who use frozen JEPA world models for planning, because closed-loop success rates systematically overstate how rankable the latent representations actually are. Frequent replanning masks broken action ranking, so systems may appear reliable even when the underlying action scorer is severely inverted. The benchmark provides a direct measurement that could influence model selection and auditing practices for latent-space planners.
Background
JEPA (Joint Embedding Predictive Architecture) world models learn latent representations to predict future embeddings without reconstructing pixels. Reward-free latent world models score candidate actions by measuring the distance between predicted future embeddings and goal embeddings, assuming that closer latent distance means better action. ARC-Bench audits whether that assumption holds in released JEPA-WM checkpoints.
Key Details
ARC-Bench uses a fixed-candidate protocol with no leakage and includes controls for provenance, undertraining, matched-budget backbones, and metric circularity. Reducing the planner's replanning frequency causes success collapse in both navigation and manipulation domains. The PointMaze first-plan diagnostic shows that episodes rescued by frequent replanning are enriched for severe first-plan ranking failures.
