Key Details
Instruction tuning optimizes models to follow specific prompt patterns, collapsing the response space; rollout policies may also contribute. The convergence is so strong that AI-generated articles are instantly recognizable despite individual plausibility.

FLUX.2 introduces changes in transformer blocks, modulation, feedforward networks, VAE normalization, and position IDs compared to FLUX.1. Background
LLM inference at scale refers to serving large language models to many users simultaneously with low latency and high throughput. Key challenges include managing GPU memory for model weights and intermediate states (KV cache), orchestrating requests via batching, and optimizing kernel execution. The handbook dissects GPU architecture, explaining that inference is often memory-bound: compute units wait for data from high-bandwidth memory (HBM), leading to low utilization. The project repository includes mermaid.js diagrams for visual explanation and is structured chapter by chapter, currently covering GPU execution and memory.
