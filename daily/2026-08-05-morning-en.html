It includes both an offline ground-truth measurement and a lightweight serving-time predictor, showing thorough empirical validation. This is technically deep and directly useful for AI practitioners.
📰 What's New
Researchers introduced JouleShare, a framework that uses Shapley values to attribute GPU energy to individual requests in batched LLM serving. The offline harness replays request subsets under the vLLM engine, integrating GPU power telemetry to compute exact Shapley energy per request. A lightweight calibration model, JCalib, then predicts Shapley shares from cheap request features like prompt length and generation length for online deployment. Across 16 model/workload runs and three data-center GPUs, token-proportional attribution deviates from exact Shapley by a normalized L1 of 0.440 under static batching and 0.458 under continuous batching; JCalib reduces the error to 0.116 and 0.177, respectively.
💡 Why It Matters： Accurate per-request energy attribution is critical for sustainability reporting, chargeback, and workload analysis as LLM serving scales. Token-based proxies are unreliable under batched execution, leading to misallocation of energy costs. JouleShare provides a deployable solution, enabling cloud providers and enterprises to fairly account for energy consumption, supporting carbon accounting and cost optimization.
📊 Key Facts: 0.440 0.458 0.116
Background
Batched LLM serving improves throughput by processing multiple requests simultaneously on GPUs, but GPU power telemetry is aggregate, complicating per-request energy accounting. Shapley values are a fair cost allocation method from cooperative game theory based on marginal contributions. vLLM is a popular open-source LLM serving engine that supports continuous batching, which dynamically adjusts the batch composition.
Key Details
The offline harness uses a reproducible protocol to replay request subsets with vLLM, capturing GPU power telemetry and computing exact Shapley energy per request. JCalib is a calibration model that learns to map cheap request features to Shapley shares, ensuring low overhead at serving time. The evaluation spans 16 model/workload combinations on three data-center GPUs, covering both static and continuous batching settings, and extends to larger batch sizes via sampled Shapley approximation.

📰 What's New

📊 Key Facts: 90% 55% -90%

Agentic coding involves AI agents that interleave multi-step LLM inference with tool usage (e.g., code execution, file operations), unlike simple chatbots. The KV cache stores intermediate attention key-value tensors to avoid recomputation during autoregressive inference. High reuse within turns indicates that multiple LLM calls in an agent loop often share the same prefix, while cross-turn boundaries reflect user-triggered context changes.
Key Details

Background
Self-evolving LLM agents adapt from stored experiences, relying on persistent memory. In cloud environments, memory quotas are dynamically adjusted; naive deletion or compression permanently discards information needed for rebuilding, leading to memory hysteresis—a persistent capability gap after budget restoration. Knowledge crystallization mimics phase transitions in physics by compressing knowledge into recoverable intermediate states instead of deleting it outright, enabling later restoration when resources increase.

Echo Gap: Memory Reward Inflation in Self-Improving LLM Agents

rss ArXiv cs.AI · 2026-08-05 · ⌛ 4 min read
Reason：The paper identifies a critical failure mode ('Echo Gap') in self-improving LLM agents, where reward inflation in memory-based systems causes compounding errors. This is a high-value technical insight for AI researchers and practitioners working on agent architectures, though not a market-relevant breakthrough.
📰 What's New
A newly identified failure mode, termed the Echo Gap, affects self-improving LLM agents that rely on stored memory evaluations. Incorrect episodes receive inflated reward scores, causing the agent to preferentially reuse its most confidently mistaken actions, and this error compounds through memory retrieval even under similarity-based retrieval. The necessary condition for correcting this inflation is formalized as the Error-Independence Assumption (EIA). Researchers introduced LUCID, an answer-free de-inflation algorithm that raises execution accuracy to 56.9% on the BIRD text-to-SQL benchmark, outperforming a self-graded agent (54.0%) and a memory-less agent (52.4%) with a mean gain of +2.9 points across seeds.
💡 Why It Matters： This finding exposes a critical safety issue in autonomous AI systems: when agents trust their own biased self-assessments without external verification, they can silently compound errors. It poses a direct risk to the long-term reliability of self-improving agents deployed in open-ended environments, and it provides a formal design requirement—the EIA—for future verifier systems.
📊 Key Facts: 56.9% 54.0% 52.4%
Background
Self-improving LLM agents use external memory to store experiences, where each episode is scored—often by the LLM itself—and later retrieved to guide future actions. Without ground-truth labels, these self-assigned proxy rewards can be inflated for incorrect trajectories, leading to a self-reinforcing cycle of error repetition known as the Echo Gap.
Key Details
The Error-Independence Assumption (EIA) requires the verifier's error to be decorrelated from the memory bias to enable correction. LUCID operates answer-free by exploiting this decorrelation. On the BIRD text-to-SQL benchmark, the inflation was shown to compound under both score-based and similarity-based retrieval, and LUCID achieved a consistent 2.9-point mean gain across random seeds.
