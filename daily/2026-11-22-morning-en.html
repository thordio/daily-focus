📰 What's New
Security researchers disclosed Ghostscript vulnerability CVE-2026-125396, which allows attackers to upload and execute shell commands via file uploads. The flaw stems from Ghostscript's role as the only full PostScript interpreter; PostScript is a complete programming language, so secure sandboxing is nontrivial. Ghostscript's built-in pseudo-sandbox has failed regularly, and no patch version is specified in the available information. Tools such as ImageMagick and ffmpeg often pass untrusted input to Ghostscript, expanding the attack surface.
💡 Why It Matters： Services that accept file uploads and convert documents or images through Ghostscript, ImageMagick, or ffmpeg are exposed to remote code execution if untrusted PostScript is processed. Since Ghostscript is the only complete PostScript implementation, defenders cannot easily replace it; they must rely on OS-level sandboxes such as seccomp and landlock. The issue affects web applications, print pipelines, and document conversion tools that pass untrusted input to these programs.
