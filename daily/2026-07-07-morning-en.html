HASE Co-Evolves Model Weights and Harness, 8B Model Matches 120B

rss ArXiv cs.AI · 2026-07-07 · ⌛ 4 min read
Reason：This paper introduces a novel self-evolving framework that co-optimizes model weights and task harness, demonstrating that a small 8B model can match a 120B model with an advanced harness, representing a potential paradigm shift in efficient and autonomous AI development.
📰 What's New
Researchers introduced Harness-Aware Self-Evolving (HASE), an agentic reinforcement learning framework where a single model can generate task solutions or edit selected harness components in a multi-turn action space. Using HASE, a Qwen3-8B model matched the text-classification performance of GPT-OSS-120B with Claude Code as the harness proposer. In alpha factor mining, HASE outperformed the reported GPT-OSS-120B baseline. It also repaired imperfect evaluation components and converged to state-of-the-art performance in circle-packing algorithm discovery.
💡 Why It Matters： HASE demonstrates that small models can match or surpass much larger ones by autonomously evolving both the external scaffolding and internal weights. This reduces reliance on massive fixed models and human-designed harnesses, potentially cutting computational costs and enabling self-sufficient deployment across diverse tasks.
Background
In AI agent systems, a 'harness' is the scaffolding around a model—prompts, tools, control flow, and evaluation metrics. Prior self-improving methods kept either weights or harness fixed while optimizing the other. HASE unifies both into a single RL loop, letting the model itself choose when to update weights or modify harness components. This builds on work like Meta-Harness that optimized harnesses end-to-end but kept weights static, representing a ‘co-evolution’ paradigm shift.
Key Details
HASE uses a multi-turn action space where the model decides at each step whether to output a task solution or edit a harness component (prompts, tools, retry logic, search procedures). Experiments used a Qwen3-8B base model. In text classification, it reached GPT-OSS-120B–level accuracy; in alpha mining, it beat that baseline; and in algorithm discovery, it auto-corrected flawed evaluation functions to achieve state-of-the-art results.

Forethought: Verifiable AI Reasoning via Neurosymbolic Programs

rss ArXiv cs.AI · 2026-07-07 · ⌛ 4 min read
Reason：Introduces a novel neurosymbolic system that fundamentally rethinks AI reasoning as explicit, verifiable programs, potentially addressing key limitations of test-time scaling and enabling inspection and modification before deployment. Represents a paradigm shift in building trustable AI reasoning, though impact depends on adoption.
📰 What's New
Researchers introduced Forethought, a neurosymbolic reasoning system that composes symbolic and neural primitives into explicit, verifiable programs. Across five benchmarks, Forethought improved base-model accuracy by about 30% relative and outperformed vanilla prompting, reinforcement learning scaffolds, and prompt-evolution methods. It enabled small models to match or exceed frontier model capabilities. A non-reasoning model augmented with Forethought competed with a dedicated reasoning model while requiring roughly three orders of magnitude less post-training investment.
💡 Why It Matters： This challenges the dominant test-time scaling paradigm by making reasoning inspectable and modifiable before deployment, reducing post-training cost and enabling trust. It allows smaller models to achieve advanced reasoning capabilities without extensive post-training, potentially changing how AI reasoning systems are built and deployed.
📊 Key Facts: 30%
Background
Neurosymbolic programming combines symbolic reasoning (rule-based and interpretable) with neural networks (pattern recognition). Test-time scaling, the current dominant approach, trains models to search over long chains of thought during inference, which is costly and not verifiable step-by-step. Forethought offers an alternative path to building modular, auditable reasoning systems.
Key Details
Forethought uses a domain-specific language to compose a library of symbolic and neural primitives into reasoning programs. It operates as a tool-calling execution kernel, is model-agnostic, and provides auditable reasoning steps. The approach requires approximately 1000x less post-training investment compared to dedicated reasoning models.

General Intuition, Kyutai, and Epic Games have jointly released MIRA, a 5-billion-parameter interactive world model trained on 10,000 hours of synthetic Rocket League gameplay data. Background
World models are generative models that simulate the dynamics of an environment, allowing agents to interact and plan within them. Rocket League is a physics-based vehicular soccer game requiring precise control and teamwork. Latent diffusion models operate in a compressed representation space for efficient generation. MIRA extends world modeling to multiplayer settings, requiring coordination across multiple viewpoints and actions.
Key Details
MIRA is a 5B-parameter latent diffusion model that generates video frame by frame in the latent space of a video representation codec. During an initial context warmup, the codec encoder maps short clips of each player's view into latent frames that seed a fixed-length context window, and then the model predicts subsequent frames autoregressively from all players' actions. The model achieves 20 FPS for 4-player simulation on a single NVIDIA B200 GPU, maintaining long-horizon coherence across multiple agents.

SwarmResearch: Orchestrating Coding Agents for Open-Ended Discovery

rss ArXiv cs.AI · 2026-07-07 · ⌛ 4 min read
Reason：Presents a novel multi-agent architecture for open-ended code optimization with strong results (13/15 tasks), directly relevant to AI practitioners and advancing automated coding agents research.
📰 What's New
arXiv paper 2607.02807 introduces SwarmResearch, an orchestrator-subagent framework that prevents convergence traps in long-running coding agents. It employs a Shepherd Agent with global context and multiple Search Agents, each operating in its own git branch with local context. On 15 open-ended optimization tasks, SwarmResearch outperforms state-of-the-art LLM-guided evolution and multi-agent techniques on 13 tasks. The orchestrator-guided scaling adapts parallelism at different search depths, yielding better solutions than fixed serial or parallel agent scaling.
💡 Why It Matters： By avoiding convergence to a single approach, SwarmResearch enables more thorough exploration of solution spaces for open-ended problems. This advancement directly impacts automated code optimization, AI-assisted research, and the development of more capable coding assistants. The framework demonstrates how structured multi-agent collaboration can overcome limitations of single long-running agents.
Background
Open-ended optimization problems have no definitive endpoint and can be improved indefinitely (e.g., code performance, algorithm design). Long-running coding agents iteratively refine solutions but often converge prematurely to a single approach due to accumulating context and a single program state being edited. SwarmResearch addresses this by maintaining diverse search branches and a high-level orchestrator.
Key Details
The architecture separates global strategy (Shepherd Agent) from local exploration (Search Agents), with each Search Agent operating in a dedicated git branch to maintain isolated context. The orchestrator dynamically adjusts parallelism at different search depths, unlike fixed scaling baselines. Experiments show that this approach leads to higher-level exploration, discovering better or comparable solutions in 13 out of 15 tasks.

BRAID: Unified Decision Process for Interleaved Multi-Modal Reasoning

rss ArXiv cs.AI · 2026-07-07 · ⌛ 5 min read
Reason：Proposes a novel method to apply RL to full interleaved multi-modal trajectories, a significant technical advancement with potential to influence research in unified multi-modal models.
📰 What's New
The BRAID framework models multi-turn text-image-text reasoning as a unified Markov decision process, enabling joint optimization of text and image generation through reinforcement learning. It computes a shared trajectory-level advantage and propagates it into both text token generation and image denoising paths, each optimized via modality-native policy gradients. A vision-language model judge scores each intermediate image for reasoning utility, providing dense turn-level feedback to improve credit assignment over long sequences. In spatial reasoning and visual perception benchmarks, BRAID consistently outperforms various baselines.
💡 Why It Matters： Existing unified multi-modal models optimize text and image generation separately, limiting the potential of reinforcement learning. BRAID's unified approach allows learning signals to propagate across modalities, potentially enhancing the reasoning capabilities of AI systems that combine language and visual outputs. This could accelerate the development of assistants that solve complex problems by generating both explanations and visual sketches.
Background
Unified multi-modal models like GPT-4 with DALL-E can alternate text and image outputs, but applying reinforcement learning to such interleaved sequences is challenging because image generation is not typically part of policy gradient updates. Previous methods apply RL only to text decisions, leaving image generation to supervised learning. BRAID treats the entire text-image-text sequence as a single MDP, where each text token and image denoising step contributes to a shared reward. This requires new formulations of advantage estimation and policy gradients tailored for interleaved modalities.
Key Details
BRAID uses a single RL objective with modality-native policy gradients: standard token-level policy gradient for text, and gradient propagation through the denoising process for images. A VLM judge scores intermediate images on reasoning utility, providing turn-level rewards to address long-horizon credit assignment. The framework was validated on spatial reasoning and visual perception tasks, where it demonstrated consistent improvements over baseline methods.

Background

Embodied agents are AI systems that perceive, reason, and act within physical or virtual environments. Foundation models are large-scale pre-trained models that can be fine-tuned for various downstream tasks. Multimodal self-attention allows direct cross-modal interactions between vision, language, and other modalities.

The modality-specific components communicate via shared multimodal self-attention.
