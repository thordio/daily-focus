FusionEval Benchmarks Model Fusion for Reasoning and Tool Use in LLMs

rss ArXiv cs.CL · 2026-10-24 · ⌛ 5 min read
Reason：Introduces a comprehensive benchmark for model fusion in LLMs, addressing key gaps in reasoning and tool-use evaluation, with practical insights on capability retention and cost trade-offs.
📰 What's New
FusionEval introduces controlled expert pools independently trained from Qwen3 and Llama base models across math, code, science, instruction following, and tool use. The evaluation suite covers eight public benchmarks and reports normalized average and worst performance, runtime, and peak GPU memory usage. Experiments show training-free fusion methods preserve reasoning performance but substantially degrade tool use at both model scales. MOPD preserves tool use and achieves a more balanced capability profile but requires additional data preparation, inference, and training.
💡 Why It Matters： FusionEval addresses a gap where strong average performance hides losses in individual expert capabilities, especially long chain-of-thought reasoning and multi-turn tool use. It gives practitioners a standardized way to compare fusion methods on capability retention and computational cost, informing whether a single fused model can replace multiple experts. The finding that jointly retaining reasoning, instruction following, and tool use at low cost remains unsolved highlights a concrete barrier for efficient LLM deployment.
Background
Model fusion integrates capabilities from multiple expert models into a single model to reduce inference cost and simplify deployment. Qwen3 and Llama are open base language model families used to train specialized experts in math, code, science, instruction following, and tool use. Tool use tasks involve multi-turn interactions where a model calls external APIs or functions. Existing fusion evaluations have rarely tested long chain-of-thought reasoning together with tool use, allowing average scores to hide failures in individual skills.
Key Details
The benchmark uses domain experts independently trained from Qwen3 and Llama base models, and evaluates them under comparable data access rules. It reports normalized average and worst performance, runtime, and peak GPU memory usage across eight public benchmarks. Training-free methods preserve reasoning but degrade tool use, while MOPD preserves tool use but requires additional data preparation, inference, and training.

IQuest-Q1: 320B Sparse MoE Agentic Foundation Model for CLI Systems

rss ArXiv cs.CL · 2026-10-24 · ⌛ 5 min read
Reason：Presents a large-scale sparse MoE agentic foundation model (320B params, 15B activated) with detailed training innovations (Stable SplitNorm, Muon, muP, multi-scaffold RL, model merging) targeting agentic coding. High technical depth and potential competitive impact for AI practitioners and investors tracking frontier model development, though no benchmark results or community discussion provided.
📰 What's New
IQuest-Q1, a 320-billion-parameter sparse Mixture-of-Experts agentic foundation model with 15 billion activated parameters, has been released as open source. It was developed through a three-stage process: pre-training combining Stable SplitNorm, Muon, and muP with a two-stage curriculum that increases coding data in the second stage; fine-grained mid-training expanding data mixture and context length; and multi-scaffold, multi-version post-training integrating SFT, domain-specialized RL, and MOPD. Model merging combines different experts and checkpoints while mitigating parameter update conflicts. The model targets coding and general tasks, optimized for CLI systems.
💡 Why It Matters： By combining 320B total parameters with only 15B activated per token, IQuest-Q1 offers a compute-efficient open-source option for agentic CLI applications, covering software engineering, long-horizon reasoning, and cybersecurity. Its release lowers barriers for researchers and developers to build on frontier-scale agentic foundation models, potentially accelerating deployment of autonomous coding and system-administration tools.
Background
Mixture-of-Experts (MoE) is a neural network design where multiple expert sub-networks exist, but only a subset is activated for each token, enabling large capacity with lower per-token compute. CLI (command-line interface) tasks require models to understand and execute text commands, often over long multi-step sessions. muP (maximal update parameterization) and Muon are techniques for stable training of large models; Stable SplitNorm is used to further stabilize optimization.
Key Details
The architecture uses sparse Mixture-of-Experts with 320B total and 15B activated parameters. Pre-training incorporates Stable SplitNorm, Muon optimizer, and muP parameterization; the two-stage curriculum increases coding-data mixture in stage two to maintain a wide stability margin between safe and optimal learning rates. Post-training uses multi-scaffold, multi-version SFT, domain-specialized RL, and MOPD, followed by model merging to reduce conflicts between parameter updates.

They extracted authentic dilemmas from classic novels and verified each conflict with a logic solver. On external benchmarks MoralChoice, ELEPHANT, and MORABLES, the policy became more decisive and invariant to option order, but sycophancy and reframing remained challenges to validity. Two ablation studies with synthetic dilemmas and unmasked thinking matched reordering gains but showed weaker register shift and higher sycophancy.
💡 Why It Matters： For AI alignment, the finding that models can become more decisive and order-invariant without actually improving moral judgment matters: developers may misinterpret consistency as reliability. Sycophancy and reframing mean the model can be swayed by how options are presented or by user cues, so deployment in moral advisory roles remains risky. The study provides a cautionary benchmark for training methods that reward argument quality rather than moral correctness.
Background
Self-rewarded moral argumentation is a training approach where a language model generates justifications for moral choices and assigns itself quality scores to guide reinforcement learning. Masked thinking hides the model's internal reasoning from the reward signal, forcing it to rely on the generated argument text. Sycophancy refers to the model aligning with the user's expected answer rather than independent judgment, while reframing is changing a moral dilemma's wording to alter the chosen response. MoralChoice, ELEPHANT, and MORABLES are standard external benchmarks for evaluating moral reasoning in language models.
Key Details
The training procedure uses a self-judged tournament with masked thinking: the policy generates arguments and judges them pairwise for quality, then adopts the rewarded language register. Dilemmas are extracted from classic novels and verified as conflicts with a logic solver. Ablations with synthetic dilemmas and unmasked thinking produced weaker register shift and higher sycophancy, isolating the effect of real novel-based dilemmas and masked reasoning.

Audit Finds 25 of 98 SWE-Milestone Tasks Have Specification-Oracle Gaps

rss ArXiv cs.CL · 2026-10-24 · ⌛ 5 min read
Reason：Identifies and quantifies a key flaw in test-graded coding-agent benchmarks, offering a formalization and static audit with strong precision/recall; high value for AI researchers and practitioners evaluating coding agents, but no broader market or economic impact. No community discussion provided.
📰 What's New
Researchers formalized and audited specification-oracle gaps in test-graded coding-agent benchmarks, where passing tests requires unstated implementation details. A static audit for five languages classified name-, path-, and literal-level dependencies of every scored test with held-out precision 89.2% and recall 92.9%. On SWE-Milestone, 25 of 98 graded milestones contain a test depending on an unstated, non-inferable name or path. Build units with such dependencies fail in 80.6% of 35 published runs, versus 48.4% for comparable units without one, and withholding a single hidden name stopped tests from compiling in 126 of 128 cases.
💡 Why It Matters： The findings show that a subset of coding-agent benchmark tasks may measure reproduction of upstream implementation details rather than problem-solving from specification. This can skew agent comparisons and favor models that copy upstream names, affecting AI researchers and engineering teams that rely on these benchmarks for model selection. Releasing corrected filters and specification addenda gives the community a concrete path to reduce that bias.
📊 Key Facts: 89.2% 92.9% 80.6%
Background
In test-graded coding benchmarks, a task is described in natural language but graded with tests from the upstream project. If a test asserts a constant name, module path, or exact message that the description never states, a correct solution may still fail due to naming choices. Specification-oracle gaps therefore conflate specification compliance with upstream implementation detail reproduction.
Key Details
The static audit models inconsistencies added by chains of dependent tasks and was applied across five languages. In four additional benchmarks, prevalence followed construction: a third or more tasks were affected where specifications were release notes or LLM summaries, while almost none were affected where tasks were screened or written for their tests. The SWE-Milestone leaderboard ranking was robust to removing affected tests, but scores shifted within repositories and favored agents that reproduce upstream names.

Compiling Autoregressive LLM Control into Policy-Exact Parallel Inference for Hierarchical RAG

rss ArXiv cs.CL · 2026-10-24 · ⌛ 5 min read
Reason：Novel technical approach for efficient LLM-based control in hierarchical RAG, potentially significant for latency and cost reduction. However, it is a specialized arxiv preprint with no community discussion or market validation provided.
📰 What's New
Researchers propose compiling autoregressive LLM control decisions in hierarchical RAG into policy-exact parallel inference using action-prefix trees. The method uses one root prefill plus one tree-causal probe to evaluate every prefix-conditioned action distribution with serial decoding's tokens, positions, and causal ancestry. A prefix-state lemma makes compiled control policy-exact in exact arithmetic, yielding a two-forward critical path and zero output tokens. Across four document-disjoint splits and two scales on the MetaX device, compiled control matches the serial policy on 84-89% of questions, with every divergence a floating-point near-tie, and cuts control latency by 35-47% versus token-wise serial decoding and 6-7% versus an idealized chunked engine.
💡 Why It Matters： This removes serialization overhead from LLM-based structured decision pipelines, shrinking the critical path to two forward passes and eliminating output-token generation for control. For hierarchical RAG and similar agentic retrieval systems, the 35-47% control latency reduction can directly lower serving cost and improve response time without changing the policy. The policy-exact guarantee in exact arithmetic, with only floating-point near-tie divergences, suggests the approach can be adopted in production where deterministic control behavior is required.
📊 Key Facts: -89% -47% -7%
Background
Hierarchical RAG breaks a document collection into a tree of sections; an LLM controller chooses which child sections to retrieve at each step, then generates an answer from the gathered context. Traditionally this control is either free-form JSON, which can fail to parse, or grammar-constrained generation, which is reliable but strictly serial. The new work notes that for bounded-horizon control, the set of possible future actions is a shallow tree, so the LLM can be probed in parallel instead of decoding token by token.
Key Details
The compiled action-prefix tree covers the reachable future for bounded-horizon control, where the LLM commits to b of k sections at each document-tree frontier under an input-dependent action grammar. One further probe pass certifies the exact order-marginalized MAP set, meaning the set of best actions is computed without enumerating serial decoding. Evaluation on the primary MetaX device and an H800 repetition shows the latency ordering is preserved, with divergences limited to floating-point near-ties.
