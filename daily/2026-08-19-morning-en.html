MoNe: Modular Neural Memory Cuts Long-Context Inference Cost by 80% at 128K Tokens

rss ArXiv cs.AI · 2026-08-19 · ⌛ 5 min read
Reason：Novel modular neural memory architecture attaches to frozen transformers, achieving O(1) query cost and ~80% compute/memory reduction at 128K tokens, a potentially paradigm-shifting advance for long-context inference. No community discussion available.
📰 What's New
MoNe, a lightweight modular neural memory, attaches to any frozen pretrained Transformer to enable long-context inference without retraining. It reads context in fixed-size segments through test-time learning of fast-weight neural memory networks with layer-localized gradient updates. At inference, the memory generates keys and values from query tokens alone, so no context tokens are re-read. At 128K tokens, MoNe reduces compute and peak GPU memory by approximately 80% compared to in-context learning, with only 6.4% parameter overhead.
💡 Why It Matters： This decouples inference cost from context length, allowing models with limited native windows to process very long documents and tasks like multi-document QA without linear memory growth. Enterprises running LLM inference can cut GPU memory and compute costs by ~80% at 128K tokens, potentially enabling larger batch sizes and cheaper long-context services. The O(1) query cost could shift how long-context inference is deployed, making models with small context windows competitive on RULER benchmarks.
📊 Key Facts: 80% 6.4%
Background
In-context learning (ICL) feeds the entire context into a Transformer's attention at every step, so compute and memory scale with context length N. Fast-weight memory networks store information by updating parameters at test time rather than adding tokens to input. A frozen pretrained transformer has fixed weights and is normally limited to its trained context window. RULER is a benchmark for evaluating long-context language models via tasks like needle-in-a-haystack and word extraction.
Key Details
MoNe uses a two-phase design: O(N) preprocessing reads context in fixed-size segments and learns fast-weight neural memory networks via layer-localized gradient updates, then O(1) query cost because memory generates keys/values from query tokens alone. Peak GPU memory does not grow with N. The architecture adds only 6.4% parameter overhead and generalizes beyond the backbone's native window, with strong results on RULER needle-in-a-haystack and word extraction tasks.

📰 What's New
Researchers introduced ASI-Bench, built by over 40 experts at a cost of 31,000+ human hours, containing 60 project-level research tasks across 11 scientific domains. The benchmark evaluated 18 state-of-the-art agent-model configurations and found average scores dropped from 50.91 with full methodological guidance to 29.10 with only the method specified and 26.62 when agents had to determine methods themselves. All tasks underwent expert review, AI-assisted auditing, sandbox execution, and scorer validation. The sharp decline indicates current AI systems depend heavily on human guidance and remain far from autonomous end-to-end research.
💡 Why It Matters： ASI-Bench addresses a gap in AI evaluation: existing benchmarks test knowledge recall and task completion under human supervision, not the ability to explore unknown problems or execute research autonomously. The measured drop quantifies how quickly performance degrades as guidance is removed, giving researchers and investors tracking artificial superintelligence a concrete progression metric. Its open submission portal may standardize benchmark tasks across scientific domains and drive development of more autonomous systems.
📊 Key Facts: 31,000 50.91 29.10
Background
Artificial superintelligence (ASI) refers to a hypothetical AI system that surpasses human cognitive performance across all domains. Most current AI benchmarks assess whether models can reproduce learned knowledge or complete narrowly scoped tasks with explicit human instructions. ASI-Bench instead requires agents to identify research problems, choose methods, and produce verifiable results with diminishing methodological guidance—an approach closer to measuring progress toward ASI.
Key Details
ASI-Bench evaluates two dimensions jointly: innovative exploration and autonomous scientific execution. It progressively withdraws human methodological guidance within the same research project to test independent method selection, research conduct, and verifiable results. The benchmark spans 11 scientific domains and uses sandbox execution plus scorer validation to verify agent outputs.

💡 Why It Matters： The shift from harmful text generation to harmful operational side effects means that agentic AI systems need runtime execution boundaries, not just prompt-level controls. 📊 Key Facts: 6,300 2,100 1,832
Background

📰 What's New
Researchers registered a paired contrast using 30 AIME 2026 items and five calls per item comparing Sonnet 5 with explicit high reasoning effort against Sonnet 5 with the effort term omitted. The explicit-high contract delivered a mean cost $0.01031 higher per call with a 95% confidence interval of +$0.00204 to +$0.01974. The accuracy difference was +0.0133 with a 95% confidence interval of -0.0267 to +0.0467, so no detectable difference was found. Cost per correct answer was $0.08665 for high-effort calls and $0.07662 for omitted-effort calls.
💡 Why It Matters： For teams paying per token, this registered contrast implies that selecting high reasoning effort on Sonnet 5 increases spend by roughly one cent per call without measurable accuracy improvement on AIME 2026; over a million calls that is about $10,310 in extra cost. AI practitioners managing API budgets should not assume the reasoning-effort parameter delivers value for similar math-reasoning tasks. The study also documents model-specific omission semantics, meaning effort defaults vary by provider and model, so cost forecasts require contract-level testing.
📊 Key Facts: 95% 95% $0.01031
Background
API buyers purchase a dated contract that includes not just a model name but also parameters such as reasoning-effort level, output rail, and price schedule. AIME 2026 is a math competition dataset used to evaluate reasoning accuracy. Sonnet 5 is an Anthropic Claude model; its API allows callers to specify reasoning effort or omit it, which changes billing. Key Details
The study used a registered paired contrast with five repeated calls per item, resampling items while retaining repeated calls. Reason：Novel zero-shot black-box defense for text-to-image safety addresses the identified benign adversarial problem, offering practical applicability to proprietary models without retraining or internal access; no community discussion provided.
📰 What's New
Researchers propose DiSCO, a zero-shot, strictly black-box prompt-level defense that operates as a plug-and-play module for any text-to-image system, requiring no retraining or access to model internals. DiSCO performs distribution-guided suffix expansion via beam search and optimizes through contrastive scoring over safe and unsafe image pools generated by the target model itself, using iterative adaptive feedback until safe content is produced. On the I2P benchmark, DiSCO reduces attack success rate by 37.7% for undefended models and 25.13% for defended models, while maintaining semantic fidelity and improving image coherence. The module is architecture-agnostic and requires no changes to the underlying model.
💡 Why It Matters： Most existing text-to-image safety defenses rely on white-box assumptions and cannot scale to proprietary models, while LLM-based black-box prompt rewriting fails on the benign adversarial problem. DiSCO shows that prompt-level optimization alone can substantially reduce NSFW generation without model access, offering a practical safety layer for commercial image generation APIs and closed-source deployments. This is especially relevant for platforms subject to content safety regulations and for providers that need to mitigate red-teaming attacks without exposing model internals.
📊 Key Facts: 37.7% 25.13%
Background
Text-to-image generative models can produce Not-Safe-For-Work content such as violence or nudity when prompted adversarially. White-box defenses require access to model parameters, gradients, or internal representations, whereas black-box defenses interact only through inputs and outputs. Red-teaming attacks deliberately craft prompts to bypass safety mechanisms; the benign adversarial problem refers to prompts that appear linguistically safe but still trigger harmful generation due to the model's learned data distribution.
Key Details
DiSCO uses beam search for suffix expansion and guides optimization via contrastive scoring between safe and unsafe image pools generated by the target model itself. The process uses iterative adaptive feedback, continuing to adjust the suffix until the generated content is classified as safe. Evaluation on the I2P benchmark under multiple red-teaming attacks reports ASR reductions of 37.7% for undefended models and 25.13% for already defended models.
